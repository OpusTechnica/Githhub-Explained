# Unified Agent Operating System: Superpowers + ECC

This project runs a hybrid architecture combining **Superpowers** (engineering methodology & behavioral discipline) with **ECC** (specialized frontend, design, marketing, and performance intelligence).

---

## The 4-Phase Operating Rhythm

### Phase 1: Intake & Brainstorming (Superpowers)
* **Rule:** NEVER start writing code immediately.
* When the user gives an idea or request, invoke `superpowers:brainstorming`.
* Clarify:
  1. Business goals and target audience.
  2. Brand aesthetic, personality, and color inspirations.
  3. Key conversion actions (primary CTA, contact form, demo request).
* Present the specification in concise, digestible chunks for user approval.

### Phase 2: Junior-Proof Plan (Superpowers + ECC)
* Delegate to **`planner`** and **`architect`** using `superpowers:writing-plans`.
* Structure the plan so clearly that an enthusiastic junior engineer with no context cannot mess it up:
  - Exact file paths.
  - Component hierarchy.
  - Design tokens (colors, typography scales, spacing).
  - Explicit test expectations (Red -> Green).

### Phase 3: Subagent-Driven Execution (Superpowers + ECC)
* Execute tasks using `superpowers:subagent-driven-development` in clean, focused contexts.
* **Design & Styling:** Follow ECC `frontend-design-direction`, `design-system`, `motion-ui`, and `liquid-glass-design`.
* **Copywriting:** Follow ECC `marketing-agent` and `content-engine` for punchy headlines and value props.
* **Coding Standards:** Follow ECC `coding-standards` (immutability, semantic HTML, modern responsive CSS).
* **TDD:** Write tests/assertions first using `superpowers:test-driven-development`.

### Phase 4: Strict Verification Gate (Superpowers + ECC)
* **Rule:** YOU ARE FORBIDDEN FROM DECLARING "DONE" UNTIL PROVEN.
* Invoke `superpowers:verification-before-completion`.
* Run the specialized verification squad:
  - **`silent-failure-hunter`**: Ensure no dead buttons, broken links, or silent JS errors.
  - **`a11y-architect`**: Check WCAG color contrast, keyboard focus, and screen-reader accessibility.
  - **`seo-specialist`**: Verify meta tags, OpenGraph previews, and JSON-LD schema.
  - **`performance-optimizer`**: Ensure images are optimized and Core Web Vitals are clean.
  - **`code-reviewer`**: Confirm no redundant CSS, clean semantics, and zero hardcoded secrets.
